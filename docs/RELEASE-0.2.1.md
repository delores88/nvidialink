# DGXBridge 0.2.1

Status: replacement release in development. Version 0.2.0 remains immutable after Marketplace rejected a secret-pattern false positive in its base64-encoded Spark executable. A decoded-byte investigation identified ordinary AArch64 ELF relocation records, not a stored credential. No scanner exclusions or review overrides are used.

The replacement packages original Spark scripts and executable files alongside a small size/hash manifest. The desktop verifies the closed file set and constructs the existing SSH transfer envelope only in memory. Release validation must scan both tagged source and the exact installed payload.

Resource settings gain draft-only Ollama first, Balanced and Builds first presets, configured-budget bars against detected hardware, advanced controls and immediate quota validation. Save remains explicit. Dependency preparation reserves its proxy CPU and memory inside the configured job budget, so a job cap equal to its client cap remains usable.

Claude Code instructions use a verified ordinary physical installation path. Codex retains a verified physical alias where package redirection requires it. No owner paths or configuration values are embedded in the public source.

Owner settings and deployment receipts remain separate from release defaults. Native laptop CPU/memory caps, hotspot/sleep verification and a production later-version updater lifecycle are not claimed by this source change.

The preparation fix was deployed separately to the owner's Spark before the desktop release. Real job `2f04cd7b419b4de4b0ef428b7f8ea978` completed with exit code 0. Docker inspection measured a 0.75-CPU / 896-MiB worker plus a 0.25-CPU / 128-MiB proxy, exactly the selected 1-CPU / 1-GiB allocation. The temporary project override was restored byte-for-byte, saved global policy was unchanged, and the existing link service was not restarted. This test prepared a tiny dependency-free lockfile; it is not a full application build or download benchmark. The focused controller suite passed 39 tests, and the Windows desktop suite passed 24 tests.

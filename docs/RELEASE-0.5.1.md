# DGXBridge 0.5.1

DGXBridge 0.5.1 is deployed to the physical Spark, installed on the physical Windows laptop with settings and pairing preserved, [published on GitHub](https://github.com/delores88/nvidialink/releases/tag/v0.5.1), and accepted by DeloresAI Marketplace. The signed-in Marketplace download matches the installed release's exact installer bytes. This closeout supplements the immutable release tag; no release asset or prior tag was replaced.

The release fixes large uploads left queued by isolated-Python imports, reports bounded builder health, prunes stale queued snapshots, improves pinned LAN uploads and resumable automatic return, and corrects USB-generation detection and request-ID wording. Return copies check disk reserve before copying and honor the worker's pump budget. Completed snapshots and content-addressed chunks remain retained; paired connections retain their slower RPC transfer path.

# RTXBridge 0.6.2

The release starts from exact source `f186d3ec7568b476ad1efc63e1ccee975bb9ecf3`. It unifies all computers in Devices, adds the interactive local network map, owner password-to-key enrollment and the RTXBridge display name. The Marketplace slug, application identifier, CLI executable and existing install/state paths remain compatible. The published installer keeps the canonical `DGXBridge_0.6.2_x64-setup.exe` name required by existing installed updaters; the Tauri-built RTXBridge installer is staged under that name without changing its bytes.

Release review adds two corrections to that base. The owner must independently confirm the ED25519 fingerprint before entering a password; a changed scan fails before password SSH or its login-profile writes. Per-attempt pin files avoid a concurrent key-only probe changing that credential connection's pin. Rename cleanup verifies each legacy shortcut target, uninstall command and startup command before removing an entry, preserving unrelated files and registrations. The source/version commits and final tests are recorded separately from the base handoff.

The guided setup and manual pinned SSH route remain distinct. Password enrollment is owner-only, uses standard input and an SSH helper environment, preserves existing authorized keys and saves a dedicated key pair and confirmed pin. It does not store a reusable password in bridge configuration. No owner password or production sign-in is inferred from an isolated test account. See [device setup and privacy](MULTI-DEVICE.md).

The map vendors three.js 0.170.0 from exact upstream commit `beab9e845f9e5ae11d648f55b24a0e910b56a85a`; the npm archive integrity, two module hashes and MIT license were verified independently. Only OrbitControls' import path is adapted. Its license and source inventory accompany the release alongside the native binary SBOMs. Source tests, browser previews, isolated SSH enrollment, real compute jobs, installed migration, GitHub publication, Marketplace admission and served downloads are separate evidence layers. Final operation receipts follow their actual completion.

This release excludes the separate 0.7.0 agent-host branch. Each compute job still uses one computer; distributed training and pooled GPU memory are not included. Real additional-computer off-LAN operation, physical reboot/logon recovery and a second-laptop password setup remain separate acceptance work.

Published product source is `70829ab713192a459d9fac3217878ab38f97dea9`. The immutable [v0.6.2 release](https://github.com/delores88/nvidialink/releases/tag/v0.6.2) contains the installer, seven native binary SBOMs, complete notices, Three.js source inventories and the sanitized installed-acceptance receipt. Windows binaries were built from that commit. ARM64 binaries were built from `86354bdb9a6353b339b4f4a9ba204f513c68dfae`; its sole later source difference is the package.json map syntax-check command, recorded in the source-equivalence receipt.
